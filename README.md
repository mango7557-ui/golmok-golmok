# 골목골목 — Golmok-Golmok

**골목의 맛과 멋을 잇다.** 지도 기반 골목상권 탐색·주문·혜택 프로토타입.

## 공개 앱과 GitHub

- 앱: https://mango7557-ui.github.io/golmok-golmok/
- 저장소: https://github.com/mango7557-ui/golmok-golmok
- GitHub Pages는 `main` 브랜치의 `/docs` 폴더를 배포합니다.
- 수정 후 `npm test`와 `npm run build:pages`를 실행하고 소스와 `docs/index.html`을 함께 커밋·푸시하면 사이트가 갱신됩니다.
- 공개 사이트에서도 실제 결제·실제 매장 접수는 수행하지 않습니다. 체험 데이터는 방문자의 브라우저에만 저장됩니다.

## 바로 실행

- `dist/index.html`: React·CSS가 포함된 단일 파일. 브라우저에서 열어 바로 체험할 수 있습니다.
- 개발 서버: `npm install` → `npm run dev` → 표시된 로컬 주소 접속.
- 배포 파일 다시 생성: `npm run build`
- 핵심 로직 검사: `npm test`
- 브라우저 흐름 검사: 개발 서버를 5173 포트로 실행하고 `node browser-check.mjs`. Playwright Chromium 필요.

## 추천 체험 순서

- 매장 목록·상세의 **하트 / 단골 등록**을 누르면 단골 매장으로 등록됩니다. 채워진 하트를 다시 누르면 해제됩니다.
- **혜택·마이 → 단골 매장**에서 단골 매장 수, 영업 상태, 적립 혜택을 확인하고 상세로 이동하거나 단골을 해제할 수 있습니다.
- 기존 하트 저장 내역은 단골 등록으로 그대로 유지됩니다. 등록 상태는 새로고침 후에도 같은 브라우저에서 유지됩니다.

1. 기본 **평일 점심**에서 지도 마커 **온기 식탁**을 선택합니다.
2. 닭구이 정식을 담고 장바구니에서 **2,000원 쿠폰**, **800P**를 적용합니다. 결제 데모 금액 **11,200원**, 예상 적립 **336P**입니다.
3. `No peanuts.` 또는 `No cilantro, sauce on the side please.`를 요청사항·채팅에 입력해 번역 데모를 확인합니다.
4. **점주 모드**에서 온기 식탁 주문을 **수락 → 준비 시작 → 준비 완료**로 변경합니다.
5. **고객 모드 → 주문·채팅 → 수령 완료**를 누르면 336P가 적립되고 성수 미션에 서로 다른 매장 1곳이 반영됩니다.
6. 환불 데모를 실행하면 포인트 사용이 복원되고 적립이 회수되며 미션도 다시 계산됩니다.
7. 점주 **쿠폰·포인트 → 쿠폰 만들기**에서 입력·초안 3개·디자인 선택·승인 후 발행을 체험합니다. 기본 시간 11:00–14:00은 식당 브레이크와 충돌하지 않습니다.
8. 점주 **영업·메뉴**에서 임시휴무·조기마감·브레이크·품절을 바꾸면 고객 화면에도 반영됩니다.
9. **혜택·마이 → 데모 설정**에서 초기화·지도 오류 대체 목록을 체험합니다. 상단 시계에서 시간대 변경도 가능합니다.

## 구현 범위

- React 19 + TypeScript + Vite + Lucide. 스타일은 의존성을 줄인 반응형 CSS.
- 지도 공급자 교체용 `MapAdapter` 인터페이스와 직접 조작하는 SVG 데모 지도. 드래그, 확대/축소, 저배율 마커 묶음, 보이는 영역 기준 재검색, 선택, 목록 전환.
- 성수의 가상 매장 15개. 날짜별 예외 → 휴무 → 요일 시간표, KST, 자정 넘김 영업. 브레이크 미등록과 없음 구분.
- 고객·점주가 공유하는 주문, 품절, 영업시간, 채팅, 쿠폰, 포인트 정책.
- 포장 수령 슬롯, 테이블 04 주문, 장바구니 교체 확인, 옵션, 금액 제한, 데모 결제, 취소·거절·환불.
- 한국어·영어·중국어 간체·일본어 UI와 메뉴. 샘플 사전 번역, 미지원 원문 전달, 자동응답 데모 표시.
- 주문 당시 가격·옵션·적립 정책 보존. 매장별 데모 원장. 완료 후 적립, 중복 처리 방지, 취소·환불 회수·복원.
- 초기 구매 실적 0곳. 초기 체험 포인트는 대응하는 welcome 원장에 기록. 성수 5곳·10곳 미션, 전국 100곳·1,000곳은 확장 예정.
- `localStorage` 스키마 v3와 초기화. 사진·폰트 네트워크 실패 시 로컬 대체 UI. ESC·포커스 가두기·모바일 safe area.

## 실제 서비스 연동이 필요한 항목

| 항목 | 현재 시제품 |
|---|---|
| 실제 지도·지오코딩·길찾기 | SVG 데모. 실점포 좌표나 길찾기 아님. 현재 위치 권한은 브라우저에서 요청하되 성수 데모 탐색 유지 |
| 매장 데이터·접수 시스템 | 가상 데이터와 동일 브라우저 내 상태만 공유 |
| 계정·Kakao OAuth·점주 인증 | 인증 없는 프로필/점주 체험 |
| 결제·해외 결제·환불 | 금전 이동 없는 데모 Payment 기록 |
| 디지털 온누리·서울페이+ | 연동 예정으로 비활성화 |
| 실시간 채팅·번역 | 로컬 메시지와 검수 가능한 고정 샘플 사전 |
| AI 쿠폰 디자인 | 규칙 기반 3개 템플릿. 금액·조건은 실제 HTML 텍스트 |
| 포인트·캠페인 보상 | 현금 가치·송금·양도·현금화 없음. 캠페인 포인트 실제 사용 불가 |
| 다중 사용자·푸시 알림 | 서버, WebSocket, 관리자 권한과 실제 알림 인프라 필요 |

이미지는 Unsplash의 분위기 참고 사진이며 가상 매장의 실제 사진이 아닙니다. 지도는 직접 제작한 도식으로 길찾기나 실제 제휴를 나타내지 않습니다. 외부 API 비밀키는 포함하지 않습니다.

## 데이터 동작 참고

- 테스트 시간은 2026-10-28 점심·휴식·저녁, 2026-11-01 휴무일 시나리오입니다.
- 성수 미션 인정 기간은 2026-10-01~12-31, 매장별 1회, 총액이 양수인 완료 주문입니다.
- 쿠폰은 유효기간 내 영업일에 사용하며 휴무일은 제외합니다. 발행 검사는 영업일 시간·브레이크 충돌을 검사합니다.
- 포인트 유효기간은 적립 시 원장에 기록됩니다. 저장소는 브라우저·주소별로 분리됩니다.
- 실제 운영에는 서버에서의 가격·혜택 검증, 인증·권한, 원장 트랜잭션과 만료 정책의 정교화가 필요합니다.
